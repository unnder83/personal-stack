# M6 运维一期（监控、备份与恢复演练、安全加固） 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给生产加监控大盘（Prometheus + Grafana + node_exporter + cAdvisor）、每日自动备份与一次真实恢复演练，以及容器/响应头/镜像层面的安全加固（SSH 密钥化按用户决定暂缓）。

**Architecture:** 监控作为生产 compose 的 `monitoring` profile（默认不启动，`deploy-release.sh` 在 `.env` 含监控开关时带 profile）；`/metrics` 由 api 暴露，仅内网可达；Grafana 经 Caddy `/grafana/*` 路由 + basic auth 对外；备份由仓库内脚本 + 宿主 systemd timer 调度；加固以 compose 的 `cap_drop`/`read_only`/`security_opt` 与 Caddy 响应头实现。

**Tech Stack:** Prometheus、Grafana、node-exporter、cAdvisor、prometheus-fastapi-instrumentator、systemd timer、fail2ban、rsync。

**Spec:** `docs/superpowers/specs/2026-09-19-personal-stack-design.md`（§11.1 监控、§11.2 备份、§11.3 安全、M6 里程碑）

## Global Constraints

- 监控栈内存预算 ≤ 500MB；启用前后用 `free -m` 与 `docker stats` 记录；不足时按优先级舍去 cAdvisor 并记录 Ruling。当前实测：总 2.6G、steady-state 可用约 1.7G（AI 会话期间更低）、swap 2G（已用约 1G）；本任务先扩 2G swap 作为缓冲。
- 监控数据与备份都在 `/srv/stack`：`monitoring/prometheus`（uid 65534）、`monitoring/grafana`（uid 472）、`backups/{db,files}`。
- 监控与备份**不得暴露到公网**：Prometheus/cAdvisor/node-exporter 不发布端口、不写 Caddy 路由；Grafana 仅 `/grafana/*` + basic auth。
- `/metrics` 仅内网（Caddy 不路由 `/metrics`），Prometheus 在 compose 网络内抓取。
- 备份：MySQL 每日 `mysqldump --single-transaction --routines --triggers | gzip`，保留 7 天日备 + 4 周周备（周备为周日日备的副本）；文件 `rsync -a --delete` 到 `/srv/stack/backups/files`；同盘备份仅防误删/损坏，不防磁盘故障（异地备份属二期）。
- 恢复演练**不得触碰生产库**：dump 恢复到独立库 `personal_stack_restore`，文件恢复到 `/tmp/restore-verify` 并校验哈希。
- 加固：所有服务 `security_opt: [no-new-privileges:true]`；`caddy`/`web`/`api`/`cloudflared` 加 `cap_drop: [ALL]` + `read_only: true` + 必要 tmpfs；`mysql` 仅 `no-new-privileges`（官方镜像入口需要特权，记录 Ruling）；Caddy 增加 HSTS 与主站 CSP（`/grafana/*` 不套 CSP）。
- 外部镜像固定到具体版本并在可行处使用 digest；本仓库自建镜像仍用 sha 标签。
- SSH 保持密码登录（用户决定），仅加 fail2ban；不修改 `/etc/ssh/sshd_config`。
- 提交信息使用中文 conventional commits；任一改动不得中断自动部署链路（push 后 Deploy 必须仍成功）。

## Review Focus

1. **监控可用且不越权**：Prometheus/Grafana 指标来自真实容器；`/metrics` 与 Prometheus 不经公网；Grafana 未认证请求返回 401。钉在 Task 2/7。
2. **备份真的可恢复**：演练把 dump 恢复进独立库并与生产逐表行数一致；文件备份能校验出与生产一致的哈希。钉在 Task 4。
3. **备份失败可见**：timer 服务失败会留下非零退出与 journal 记录；脚本对缺文件/缺 env 快速失败。钉在 Task 3（`test_backup_scripts.sh`）与 Task 7（`systemctl status` 检查）。
4. **加固不破坏服务**：加固后 5 个生产容器全部 healthy、公网 200、自动部署仍成功；若某服务与 `read_only` 冲突，按最小让步调整并记录。钉在 Task 6。
5. **响应头正确且不误伤**：主站有 CSP 与 HSTS；`/grafana/*` 无 CSP；CSP 不阻断 SPA 的资源（浏览器实测登录/博客/网盘）。钉在 Task 6/7。

- [ ] **Step 2: 写备份脚本**

`deploy/ops/backup/backup-db.sh`：

```bash
#!/usr/bin/env bash
# 每日备份 MySQL：保留 7 天日备 + 4 周周备（周日副本）
set -euo pipefail

ROOT="${ROOT:-/opt/personal-stack}"
ENV_FILE="$ROOT/.env"
BACKUP_DIR="${BACKUP_DIR:-/srv/stack/backups/db}"

[ -f "$ENV_FILE" ] || { echo "缺少 $ENV_FILE" >&2; exit 1; }
[ -d "$ROOT/current" ] || { echo "缺少 $ROOT/current" >&2; exit 1; }

set -a
# shellcheck disable=SC1090
. "$ENV_FILE"
set +a

COMPOSE=(docker compose -p personal-stack --env-file "$ENV_FILE" \
  --env-file "$ROOT/current/deploy/.images" -f "$ROOT/current/deploy/compose.yaml")

mkdir -p "$BACKUP_DIR/daily" "$BACKUP_DIR/weekly"
STAMP="$(date +%F)"
TARGET="$BACKUP_DIR/daily/personal_stack-$STAMP.sql.gz"

"${COMPOSE[@]}" exec -T mysql mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" \
  --single-transaction --routines --triggers "$MYSQL_DATABASE" | gzip > "$TARGET"
echo "已备份：$TARGET ($(du -h "$TARGET" | cut -f1))"

if [ "$(date +%u)" = "7" ]; then
  cp "$TARGET" "$BACKUP_DIR/weekly/personal_stack-$STAMP.sql.gz"
  echo "已生成周备副本"
fi

find "$BACKUP_DIR/daily" -name 'personal_stack-*.sql.gz' -mtime +7 -delete
find "$BACKUP_DIR/weekly" -name 'personal_stack-*.sql.gz' -mtime +28 -delete
```

`deploy/ops/backup/backup-files.sh`：

```bash
#!/usr/bin/env bash
# 文件备份：镜像 /srv/stack/data/files 到备份目录
set -euo pipefail

SRC="${SRC:-/srv/stack/data/files}"
DEST="${DEST:-/srv/stack/backups/files}"

[ -d "$SRC" ] || { echo "缺少源目录 $SRC" >&2; exit 1; }
mkdir -p "$DEST"
rsync -a --delete "$SRC/" "$DEST/"
```

**Interfaces:**

- [ ] **Step 1: 写恢复脚本**

`deploy/ops/backup/restore.sh`：

```bash
#!/usr/bin/env bash
# 用法：
#   restore.sh --db <dump.sql.gz> [--target-db personal_stack_restore]
#   restore.sh --files <backup-dir> --target <restore-dir>
# 安全：默认恢复到 *_restore 库；恢复到生产库需显式 --target-db personal_stack 且交互确认。
set -euo pipefail

ROOT="${ROOT:-/opt/personal-stack}"
ENV_FILE="$ROOT/.env"
[ -f "$ENV_FILE" ] || { echo "缺少 $ENV_FILE" >&2; exit 1; }

set -a
# shellcheck disable=SC1090
. "$ENV_FILE"
set +a

COMPOSE=(docker compose -p personal-stack --env-file "$ENV_FILE" \
  --env-file "$ROOT/current/deploy/.images" -f "$ROOT/current/deploy/compose.yaml")

usage() {
  echo "用法：$0 --db <dump.sql.gz> [--target-db <db>] | --files <dir> --target <dir>" >&2
  exit 1
}

MODE="${1:-}"
shift || true

case "$MODE" in
  --files)
    SRC=""
    TARGET=""
    while [ $# -gt 0 ]; do
      case "$1" in
        --target) TARGET="${2:?缺少 --target 的值}"; shift 2 ;;
        *) SRC="$1"; shift ;;
      esac
    done
    [ -n "$SRC" ] && [ -n "$TARGET" ] || usage
    [ -d "$SRC" ] || { echo "备份目录不存在：$SRC" >&2; exit 1; }
    mkdir -p "$TARGET"
    rsync -a "$SRC/" "$TARGET/"
    echo "文件已恢复到 $TARGET（$(du -sh "$TARGET" | cut -f1)）"
    ;;
  --db)
    DUMP=""
    TARGET_DB="personal_stack_restore"
    while [ $# -gt 0 ]; do
      case "$1" in
        --target-db) TARGET_DB="${2:?缺少 --target-db 的值}"; shift 2 ;;
        *) DUMP="$1"; shift ;;
      esac
    done
    [ -n "$DUMP" ] || usage
    [ -f "$DUMP" ] || { echo "dump 不存在：$DUMP" >&2; exit 1; }
    if [ "$TARGET_DB" = "$MYSQL_DATABASE" ]; then
      echo "警告：即将覆盖生产库 $MYSQL_DATABASE" >&2
      read -r -p "输入 yes 确认：" answer
      [ "$answer" = "yes" ] || { echo "已取消" >&2; exit 1; }
    else
      "${COMPOSE[@]}" exec -T mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" \
        -e "CREATE DATABASE IF NOT EXISTS \`$TARGET_DB\` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
    fi
    gunzip -c "$DUMP" | "${COMPOSE[@]}" exec -T mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" "$TARGET_DB"
    echo "数据库已恢复到 $TARGET_DB"
    ;;
  *)
    usage
    ;;
esac
```
